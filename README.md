# GPT + Claude chat starter

A Next.js app with one chat interface and a model picker for Auto, GPT, or Claude.

## Run locally

Requires Node.js 20.9 or later. Copy `.env.example` to `.env.local`, add the API key(s) you have, then run `npm install` and `npm run dev`. Open http://localhost:3000.

Never commit `.env.local` or share your API keys. Requests are billed by the AI providers. This starter has no user sign-in, persistent chat history, or public-deployment rate limiting; do not expose an unauthenticated deployment without adding those protections.
